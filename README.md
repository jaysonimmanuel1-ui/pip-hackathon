✨ Pip — An Interactive Web Experience
A playful, colorful, and interactive website built for a hackathon.
Pip is a creative web experience featuring animations, interactive elements, and a playful Chaos Mode designed to make exploring the website fun and engaging.
🌟 Features
- 🎨 Interactive Design — A colorful interface with playful visual elements.
- 🎲 Chaos Mode — Toggle an animated, more dynamic visual experience.
- 🖱️ Animated Cursor Trail — Colorful effects follow the cursor as you move around the page.
- 🌙 Theme Toggle — Switch between available visual themes.
- 🔊 Sound Controls — Toggle the website's sound setting.
- 💬 Interactive Chat — Explore the chat interface with Pip.
- 💌 Guestbook — Interact with the wishes section.
- 📱 Responsive Layout — Designed to adapt to different screen sizes.
- ✨ Animated Interactions — Discover surprises and visual effects throughout the experience.
🛠️ Built With
- HTML5
- CSS3
- JavaScript
The project is designed as a front-end web experience and can be opened in a modern web browser.
🚀 Getting Started
Run Locally
1. Clone this repository:
   git clone https://github.com/jaysonimmanuel1-ui/pip-hackathon.git
2. Open the project folder:
   cd pip-hackathon
3. Open index.html in your browser.
No package installation or build step is required for the basic website.
